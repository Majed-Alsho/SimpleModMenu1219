# Baseline Snapshot — single-screen mods UI

**Tag:** `baseline-single-screen-v1`  
**What’s included**
- Single-screen `ModsScreen` with left list (mods only from real `.minecraft/mods`) and right detail pane.
- Search filter.
- Buttons: Configure (ModMenu shim), Reveal File, Copy ID, Copy Version.
- Clickable Homepage/Sources/Issues links with manual hitboxes.
- Custom scroll handling; no fragile @Override usage.
- Safe path handling and small HUD toasts.

**Known not included**
- Separate ModDetailScreen (unused).
- Icons, update dots, keybind.
